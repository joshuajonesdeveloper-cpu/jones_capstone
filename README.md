# Ironside Training Co

Joshua Jones — ITD 210 capstone project.

This site introduces a personal training studio in Woodbridge, Virginia. The Home and About pages share the same header, footer, SVG logo, and stylesheet. The About page uses a two-column story layout, a responsive values grid, and an accessible hand-written barbell logo.

Open `index.html` to view the site. The layout adapts to phones and desktops, and the mobile navigation opens with the menu button. Services, Gallery, and Contact currently provide basic navigation pages for later capstone work.

Development security checks are configured with ESLint and its security plugin. Dependabot configuration covers npm packages and GitHub Actions. The Gitleaks workflow scans pushes and pull requests for secrets. Repository security settings and deployment scan results must be verified on GitHub and the deployed site; the presence of these configuration files alone does not prove those checks have run.
